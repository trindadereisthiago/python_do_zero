# Python do Zero

Repositório criado para armazenar os exercícios e projetos desenvolvidos durante meus estudos de Python.

## 📚 Objetivo

Praticar os principais conceitos da linguagem Python, como:

- Variáveis
- Estruturas condicionais
- Laços de repetição
- Funções
- Listas, tuplas e dicionários
- Manipulação de arquivos
- Programação orientada a objetos
- Bibliotecas

## 📂 Estrutura

```
python_do_zero/
│
├── aula01/
├── aula02/
├── projetos/
├── README.md
```

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu_usuario/python_do_zero.git
```

2. Entre na pasta:

```bash
cd python_do_zero
```

3. Execute um arquivo:

```bash
python nome_do_arquivo.py
```
